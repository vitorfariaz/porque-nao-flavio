Todos os links foram limpos de parâmetros de rastreamento (`fbclid`, `utm_*`).

## Metodologia

- Prioridade para veículos de imprensa, órgãos oficiais e agências de checagem.
- Onde a reportagem não sustenta a frase como ela foi escrita, a frase foi corrigida e a divergência está registrada na nota.
- Afirmações que são opinião (e não fato verificável) foram substituídas pelo dado objetivo correspondente, com a troca sinalizada.
- Itens sem fonte encontrada ficam marcados como `<não encontrado notícia sobre isso>` em vez de serem publicados sem lastro.

Correções são bem-vindas: abra uma issue com o link da reportagem.
